## 🚀 How to Deploy to GitHub Pages (`wipaveenan.github.io`)
1. Create a new repository on GitHub (e.g., `canan-portfolio-2026` or `wipaveenan.github.io`).
2. Extract and upload all files and folders from `canan-portfolio-2026-github.zip` (`index.html`, `css/`, `js/`, `assets/`, `.nojekyll`, `README.md`) to the root of your repository.
3. Go to **Settings → Pages** in your GitHub repository.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` (and `/ (root)`), and click **Save**.
5. Your live responsive portfolio website will be published within 1–2 minutes!
